# 幻想肖像画美術館 ポートフォリオサイト

「幻想肖像画美術館_ポートフォリオHP制作仕様書_Q001-Q020_確定版.md」に基づいて構築した、
静的HTML/CSS/最小限のJavaScriptのみで動くポートフォリオサイトです。
フレームワーク・ビルド工程は使用していません。ファイルをそのままサーバーに置けば動作します。

**このフォルダ（`asaHP_本体`）が、そのままGitHubに読み込める公開用の中身です。**

配色テーマ：**ネイビー×ゴールド（夜の展示室）**
ページ構成：**ホーム（額縁の壁）／ABOUT（自己紹介）／CONTACT** の3ページ
CONTACTフォームの送信方式：**Googleフォーム連携**（隠しiframe経由でページ遷移せずに送信）

- **ホーム（`index.html`）** … ロゴのすぐ下から額縁の並ぶ壁。中央の額縁（肖像・位置固定）が ABOUT
  ページへのリンク、周囲の6額縁が活動展示（note・LOOP BATTLEなど外部リンク）。左下の椅子のそばに、
  飾り画像も追加できます。
- **ABOUT（`about.html`）** … 肖像（声の活動⇔美術館ガイドの切替）・自己紹介文。
  **声の活動の姿のときは VOICE SAMPLE、美術館ガイドの姿のときは創作イラストなどの添付物**が表示されます。
  額縁と自己紹介の並び（縦／左右）はエディターで変えられます。
- **CONTACT（`contact.html`）** … お問い合わせフォーム（記入項目は自由に増減・必須設定できます）。
- **トピック（`topics.html`）** … 「ぎんがむたんぽぽ・サロン広報」。サロンメンバー最大3人の紹介
  （画像・リンク・紹介文・イメージ音楽の試聴）と、最近のトピック最大3記事（新しい順・いちばん新しい記事に
  NEWのワッペン）。ホーム左下の椅子横の飾り画像から開きます。

## 0. asaHPフォルダ全体の構成（この README があるフォルダの、ひとつ上の階層）

```

├── asaHP_本体/                … ★この README があるフォルダ。GitHubに上げる中身はここだけ★
```

中身は次のとおりで、どれも消すとasaHPエディターが動かなくなります。

| `.devserver/asaHPエディター_アイコン元画像.png` | ↑の元画像 |

| `.claude/launch.json` | Claude Code でプレビューするための設定 |

`asaHPエディター.lnk` をダブルクリックすると、ローカルサーバーを起動したうえで
既定のブラウザに `asaHPエディター` が開きます（2章）。

## デザインの仕組み（背景と額縁）

通信を軽くするため、豪華な部屋は**1枚の背景画像**で表現し、その額縁の絵の部分に
肖像画・展示画像を**重ねて**います。額縁の位置は固定です。

| 画面 | 背景画像 | 構図 |
|---|---|---|
| スマホ（縦長） | `room_mobile.jpg` | 中央の大額縁＝本人の肖像（ABOUTへ、位置固定）、周囲の6額縁＝活動展示、左下＝椅子・飾り画像 |
| PC（横長） | `room_pc.jpg` | 6額縁＝活動展示、左上＝肖像（額縁画像`portrait_frame.png`付き）、壁の下のパネル＝ロゴ、左下＝椅子・飾り画像 |
| スマホ冒頭 | `hero_exterior.jpg` | ロゴを重ねる |
| ABOUT | なし（`room.aboutBackground` で設定可能） | 紺色のグラデーションのみが標準 |
| CONTACT | `contact_bg.jpg` | 暗くして背景に使用 |

元画像（数MB）は、表示が速くなるようJPEGに縮小・圧縮して `assets/images/` に入れています。
背景全体の明るさは `data/config.js` の `room.brightness`（数字を大きくすると明るくなります）で
調整できます。

### 展示に入れる画像の目安

額縁は絵の中央を基準に切り取って表示します（比率が違っても崩れません）。
長い辺が600px程度、JPEG/WebPで100KB以下を目安にすると軽く動きます。
それぞれの額縁の正確な形（縦長・横長・正方形・楕円）は、**2章の asaHPエディターで
実際の大きさを見ながら確認**してください。

※ 展示の `image:` を空欄 `""` にすると、背景に描かれている絵がそのまま見えます。

### 椅子横の飾り画像（座っている人など）

PC画面の左下に置く飾り画像は、asaHPエディターの「ホームページ」ノートで、
**枠の位置・大きさをドラッグで決めてから**、その枠に合わせて絵を作るのがおすすめです。
枠は背景の外へはみ出してもよく、はみ出した部分はサイトでは表示されません
（画面の端で自然に切れる絵を置けます）。枠に画像を設定すると、エディターの
プレビューの枠内にその画像が表示されるので、見え方を確認しながら調整できます。

## 2. asaHPエディター（ローカル管理ツール）

サイトの内容・レイアウトは、`data/config.js` と `data/layout.js` を直接書き換えても
更新できますが、**asaHPエディターを使うと、画面を見ながら・フォームに入力しながら
安全に更新できます**。

### 開き方

`asaHP` フォルダ直下の **`asaHPエディター.lnk`**（フクロウのアイコン）をダブルクリックして
ください。ローカルサーバーが（起動していなければ自動で）立ち上がり、既定のブラウザで
asaHPエディターが開きます。

- 左のサイドバーに「ノート」（作業項目）が並ぶシンプルな構成です。
- ノートはすべて **黒基調のシンプルなデザイン**で、サイト本体の金色の装飾は使っていません。
- 各ノートの内容はiframeで表示され、切り替えても入力中の内容はそのまま残ります。

### ノート一覧

| ノート | できること |
|---|---|
| ホームページ | **タイトルロゴ**（画像・大きさ・添える一言）、活動展示6枠の**画像・リンク・公開設定・並び順**（位置・大きさは固定）、椅子横の飾り画像の**位置調整（ドラッグ）＋画像・リンク** |
| （共通） | 画像・音声の欄はすべて「画像を選ぶ」ボタンからパソコンの中のファイルを選べます（3章） |
| 自己紹介ページ | ABOUTページの背景・2つの姿の肖像画とプロフィール・VOICE SAMPLE・創作イラストなどの添付物 |
| コンタクトページ | CONTACTページの背景・説明文・記入項目（追加・削除・必須切替）・依頼用テンプレート・Googleフォーム連携 |
| トピックページ | サロン広報ページのタイトル・サロンメンバー3人（画像・リンク・紹介文・音楽タイトル・イメージ音楽）・最近のトピック3記事 |
| 表示確認 | ホーム／ABOUT／CONTACT／トピックの各ページを、スマホ表示・PC表示のボタンで切り替えてその場で確認 |

「ホームページ」ノートの使い方：

1. いちばん上の「タイトルロゴ」で、ロゴ画像を差し替え、スマホ・PCそれぞれの
   大きさ（横幅の％）と、ロゴの下に添える一言を決める。下のプレビューで
   見え方を確認できます
   （PCではロゴは壁の下側のパネルに、スマホでは外観写真の下側に表示されます）
2. 上部の配置プレビューで、「スマホ用」「PC用」のタブを切り替えながら、椅子横の
   飾り画像の枠をドラッグして動かす／右下の■をドラッグして大きさを変える
   （右側の数字を直接書き換えても調整できます。展示1〜6の枠は位置・大きさが
   固定のため、参考表示のみでドラッグはできません）
   - 椅子横の飾り画像の枠は、**背景の外へはみ出してもかまいません**。
     はみ出した部分はサイトでは表示されません（座っている人など、画面の端で
     自然に切れる絵を置くときに使います）
   - 枠に画像を設定していると、プレビューの枠の中にその画像が表示されるので、
     大きさ・位置を合わせやすくなります
3. その下の「活動展示（6枠）」で、各展示の名前・画像ファイル・リンクURL・公開設定を
   入力し、▲▼ボタンで並び順（＝優先順位。上にあるものほど目立つ額縁に入ります）を変える
4. 「椅子横の飾り画像」で、画像ファイル・リンクURL・公開設定を入力する
5. 3章の方法で保存する

## 3. 画像・音声を差し替える／変更を保存する

### 画像・音声の差し替え（「画像を選ぶ」ボタン）

画像や音声の入力欄の下にある **「画像を選ぶ」**（音声の欄は「音声を選ぶ」）を押すと、
パソコンのファイル選択画面が開きます。ファイルを選ぶと、

1. そのファイルが `assets/images/`（音声は `assets/audio/`）へ自動でコピーされ、
2. 入力欄にそのファイル名が自動で入り、
3. 欄の横に小さなプレビューが表示されます。

同じ名前のファイルがすでにある場合は `〇〇_2.png` のように別名で保存するので、
前の画像が消えることはありません。取り込めるのは画像（png/jpg/webp/gif/svg）と
音声・動画（mp3/m4a/wav/ogg/mp4/webm）だけです。

※ ファイルを取り込んだ時点では、まだサイトには反映されていません。
下の「変更をすべて保存」を押して確定してください。

### 変更の保存（「変更をすべて保存」）

asaHPエディター右上の **「変更をすべて保存」** ボタンを押すと、開いているすべての
ノートの未保存の変更が、まとめて `asaHP_本体` の中身（`data/config.js` /
`data/layout.js`）に直接書き込まれます。コードをコピー＆ペーストする必要はありません。

- 変更があるノートには、サイドバーに **オレンジの丸印** が付きます。
- 保存中・保存後は、ボタンの左側にメッセージが表示されます
  （「保存しました：◯◯」「保存できませんでした：◯◯」など）。
- ページを閉じようとしたときに未保存の変更があれば、ブラウザが確認メッセージを出します。

「自己紹介ページ」ノートと「コンタクトページ」ノート（と「ホームページ」ノートの
活動展示・飾り画像の中身）は、どれも同じ `data/config.js` を編集します。保存するときは、
**保存の直前にサーバー上の今の中身を読み直してから**自分が担当する項目だけを書き換える
ので、あるノートで保存した内容が、別のノートの保存で消えてしまうことはありません。

※ この保存機能は、`asaHPエディター.lnk` から開いた場合（ローカルサーバー経由）に
使えます。`.devserver/server.ps1` が保存用の窓口を兼ねているため、`.html` ファイルを
直接ダブルクリックして開いた場合は保存できません。必ずショートカットから開いてください。

## 4. 内容を更新する方法（最重要）

**`data/config.js` を開いて、日本語コメントに沿って書き換えるだけ**です。
HTMLやCSSには触れる必要はありません。

編集できる項目：

| 項目 | 内容 |
|---|---|
| `museumName` | 美術館名（ロゴ横のテキスト） |
| `room` | 背景画像（スマホ用・PC用・外観・ABOUT・CONTACT）と明るさ（`brightness`）。ホーム背景は額縁位置と一体の画像なので、差し替えは同じ配置の画像のみ |
| `home.sideDecor` | ホーム左下の椅子のそばに置く飾り画像・リンク（「ホームページ」ノートで編集） |
| `profiles.voice` / `profiles.guide` | 声の活動／美術館ガイド、2つの姿の名前・肩書き・自己紹介（改行OK）・肖像画像 |
| `voiceSamples` | VOICE SAMPLE（ABOUT・最大4件）。`published: false` で非表示 |
| `attachments` | 創作イラストなどの添付物（ABOUT・最大8件）。`published: false` で非表示 |
| `exhibits` | 活動展示6枠（ホーム）。**配列の並び順＝優先順位**（先頭ほど目立つ大きな額縁）。`published: false` で非表示（次の展示が繰り上がります）。位置・大きさは固定で「ホームページ」ノートの対象外 |
| `contact.leadText` | CONTACTページのフォーム上部に表示する説明文（仕様案内） |
| `contact.fields` | CONTACTの記入項目（5章を参照。項目の追加・必須/任意の切替ができます） |
| `contact.requestTemplate` | 「依頼用テンプレートを挿入」ボタンの文面 |
| `contact.googleForm` | CONTACTフォームの送信先（6章を参照） |

上記のうち、`exhibits`・`home.sideDecor` は「ホームページ」ノートで、`profiles`・
`voiceSamples`・`attachments`・`room.aboutBackground` は「自己紹介ページ」ノートで、
`contact.*` と `room.contactBackground` は「コンタクトページ」ノートで、
画面から編集できます（2章）。

- `published: false` にした項目は、空枠を残さず自動的に非表示になります。
- 画像を差し替えたい場合は `assets/images/` に新しい画像ファイルを入れて、
  `config.js` 内の該当する `image:` の値をそのファイル名に書き換えてください。
  （例: `assets/images/portrait_voice.svg` → `assets/images/portrait_voice.jpg`）
- 音声ファイルは `assets/audio/` に入れて、`voiceSamples` の `src:` に
  ファイル名を指定してください。

## 5. CONTACTの記入項目を増やす・必須にする／しない

「コンタクトページ」ノート（2章）の「記入項目」から、＋ボタンで項目を追加、
「削除」ボタンで項目を減らせます。ここでは、直接 `data/config.js` を編集する場合の
書き方を説明します。

`data/config.js` の `contact.fields` は、上から順番に表示される記入項目の配列です。
初期状態は「名前・メールアドレス・問い合わせ内容」の3項目です。

```js
fields: [
  { key: "name",    label: "名前",         type: "text",     required: true,  entryId: "entry.111" },
  { key: "email",   label: "メールアドレス", type: "email",    required: true,  entryId: "entry.222" },
  { key: "message", label: "問い合わせ内容", type: "textarea", required: true,  entryId: "entry.333", template: true }
]
```

- **項目を増やす** … `{ }` のかたまりを丸ごとコピーして配列に追加する（例：電話番号、ご予算など）
- **必須にする／しない** … `required` を `true` / `false` に変える
- **1行入力にする** … `type` を `"text"`（通常）／ `"email"`（メール形式）／ `"tel"`（電話番号）に
- **複数行入力にする** … `type: "textarea"`
- **依頼用テンプレートボタンを付ける** … その項目に `template: true` を追加（1つの項目だけに付ければ十分です）
- `entryId` は、対応するGoogleフォームの質問のentry番号です（次の6章を参照）。
  項目を追加したら、Googleフォーム側にも同じ質問を追加して、entry番号をここに書いてください。

## 6. CONTACTフォームの設定方法（Googleフォーム連携）

初期状態ではCONTACTフォームの送信先が未設定のため、送信ボタンを押すと
「送信先が未設定です」というメッセージが出ます。以下の手順で設定してください。

### 手順

1. Googleフォームで新しいフォームを作成し、`contact.fields` と同じ質問を追加する
   （初期状態なら、名前／メールアドレス／問い合わせ内容の3つ。記述式でOK）
2. 作成したフォームを一度「プレビュー」で開く
3. 各質問を右クリック→「検証」（開発者ツール）で `name="entry.xxxxxxxxx"` の
   数字部分を確認する
   - もしくは、フォームの「回答」タブではなく「事前入力リンクを取得」機能を使い、
     生成されたURLに含まれる `entry.xxxxxxxxx=` の数字を読み取る方法でも可
4. フォームの「送信」ボタンのリンク（`https://docs.google.com/forms/d/e/●●●/viewform`）
   の `●●●` の部分（フォームID）を控える
5. `data/config.js` の `contact.fields` の各 `entryId` と、`contact.googleForm.actionUrl` を
   書き換える

```js
googleForm: {
  actionUrl: "https://docs.google.com/forms/d/e/【フォームID】/formResponse"
}
```

6. フォームの回答は、Googleフォームに紐づくスプレッドシートで確認できます
   （フォーム編集画面の「回答」タブ→スプレッドシートのアイコン）。

※ この送信方式はページ遷移せずに裏側でフォームへ送るため、送信後の
「送信しました」の表示は、通信自体が行われたことをもとに表示しています。
確実性を重視する場合は、Googleフォームの回答スプレッドシートに通知メールを
設定しておくことをおすすめします（フォームの「回答」タブ→点メニュー→
「新しい回答についてのメール通知を受け取る」）。

## GitHubで公開する手順

このフォルダ（`asaHP_本体`）の**中身**が、そのまま公開用の中身です。
フォルダごとではなく、中身（`index.html` などが直下に来るように）を入れてください。

1. GitHubで空のリポジトリを作る（**Public**／README・.gitignore・ライセンスは追加しない）
2. このフォルダの中身をアップロードする
3. リポジトリの `Settings` → `Pages` → `Source` を `Deploy from a branch`、
   ブランチを `main` / フォルダを `/ (root)` にして `Save`
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### 入っているもの

| ファイル | 役割 |
| --- | --- |
| `index.html` / `about.html` / `topics.html` / `contact.html` | サイトの4ページ |
| `404.html` | 存在しないURLを開いたときの案内ページ |
| `.nojekyll` | GitHub Pages の余計な変換を止めるための空ファイル（消さないでください） |
| `data/config.js` | 文章・画像・リンクなどの設定（asaHPエディターが書き換えます） |
| `data/layout.js` | 額縁の位置とサイズ |
| `assets/` | 画像・音声 |
| `css/` `js/` | 見た目と動き |
| `tools/` `asaHPエディター.html` | asaHPエディター（保存機能はパソコン上でのみ動きます） |

### 公開後に内容を変えるとき

asaHPエディターで編集して保存すると、このフォルダの中身が書き換わります。
そのあと、変わったファイルをGitHubにアップロードし直せば、数分で公開サイトにも反映されます。
